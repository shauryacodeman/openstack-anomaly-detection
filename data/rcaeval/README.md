# RCAEval RE3-OB data

This directory contains the 30 Online Boutique fault runs used by the neural model comparison. Each run includes `logs.parquet`, `traces.parquet`, and `inject_time.txt`. These files come from the pinned RCAEval release on Hugging Face. [Dataset revision](https://huggingface.co/datasets/phamquiluan/RCAEval/tree/afeacb11bcc94dadfd1c8f483ee4377b2b8b614e)

The dataset card lists the MIT license. The upstream copyright and license notice is included in this directory. [Dataset card](https://huggingface.co/datasets/phamquiluan/RCAEval) · [MIT license](LICENSE)
